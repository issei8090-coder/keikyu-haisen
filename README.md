# 京急線 配線図シミュレーター

京急線(と都営浅草線・京成線・北総線など)の配線図の上で、2025年の時刻表どおりに列車を走らせるシミュレーターです。泉岳寺〜京急川崎は信号機つきの運転指令画面もあります。

- 画面: https://issei8090-coder.github.io/keikyu-haisen/
- 画面右の「運用の編集」で、消える列車・現れる列車をつないだり、回送を足したりできます。編集キーを入れると、編集は `data/` に保存されてほかの端末でも見られます(保存は Render のサーバー `server/` 経由)。

## 作り方
`build/` で `python tools/assemble.py`(`src/` と各 JSON を1つの `index.html` にまとめる)。
