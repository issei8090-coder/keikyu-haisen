        運用の編集

        編集は画面の下に広げて行います(上のバーの「運用の編集」でも開閉)。

        列車を投入(手動)
        種別

        使い方

        上の時刻表で平日/土休日を選ぶと、2025年京急全線時刻表どおりに列車が走ります(スライダーで時刻を移動、列車をクリックすると時刻を表示)。手動投入は、図の線路をクリックするとその位置から投入できます(ホーム付近は停止位置に吸着)。列車をクリックすると選択され、行先変更・折り返し・抑止・削除ができます。※ と # は次の段への接続です。泉岳寺では都営浅草線(押上方面)からの列車が京急本線と西馬込方面に分かれます。始発・行先に「都営浅草線」を選ぶと直通列車になります。

        運用の編集

        駅で消える・現れる列車

          列車の運用

          地図・一覧・番線使用図で列車を選ぶか、左の「開く」で、その列車の前後の運用・番線・折り返し・切り離し・1日の始まりと終わりをここで直せます。

          回送(駅・通過/停車・時刻・番線)

          編集の一覧

            時刻表の時刻は変えません。駅を選ぶと、その駅で消える列車(消)・現れる列車(現)と、夜間留置・入出庫で片づいた列車(終・始)が時刻順に出ます。消と現を1本ずつ押して「つなぐ」、または「開く」でその列車の運用の設定(前・次の運用、番線、折り返しの引上線と時刻、1日の始まり・終わり、通過待ち)を開きます。消・現を選ぶと、車庫・留置線のある駅(宗吾参道など)との回送をセットで足せます(往復してつなぐ・入庫・出庫)。「案を作る」は、同じ駅の同じ所属の列車を着いた順につなぎ、残りを入出庫・夜間留置にする下書きです。ぶつかった編集には原因の列車が出るので、その列車を開くか空いている番線へ移します。

            番線使用図

            帯 = その線を押さえている時間(停車・折り返し・留置)。赤 = 同じ線を同時に使っている(縦列やぶつかり)、点線 = 回送、黄色の枠 = 選んでいる列車。帯を押すとその列車の運用の設定を開きます。
