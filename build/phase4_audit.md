# フェーズ4 調査記録：信号・速度照査

## 結論

現状の `index.html` には、手動列車の信号現示計算、閉そく信号、C-ATS速度照査の実装が見当たらない。ユーザー提供の信号・C-ATS説明書とスクリーンショットから、表示上の要件と一部の数値は確認できたが、信号位置・対象線路/方向・図上距離と実距離の対応・複数の制動値の意味はまだ確定できない。したがって、これらを実際の運転制約として列車へ適用する変更は行わない。

## 調査した実装

- 線路エッジはノード接続・方向・高架フラグを持ち、長さは図上座標から `Math.hypot` で算出される。閉そく境界、信号位置、速度制限値はエッジデータにない。
- 手動列車は `ACC`、`VMAX` と次の停車目標、先行列車との区間占有を使って走行する。信号現示や照査曲線を運動制御へ渡す経路はない。
- 線路エッジ長は配線図の SVG 座標上のピクセル距離で、現行の手動列車は `VMAX = 30`、`ACC = 28` の図上単位で移動している。駅間実距離との換算がなく、映像から採用した km/h 値をこの運動へ適用できない。
- 「根古屋信号場」の `sigStraight` / `sigSiding` は時刻表列車の経路選択用で、信号現示・車上速度照査ではない。
- 時刻表列車は別の `ttFollow` で予定位置に追従し、追従間隔と回復速度を制限する。C-ATSモデルは確認できない。
- `index.html` 内を `C-ATS`、`ATS`、`speedLimit`、速度照査、信号現示、速度制限の語で検索したが、該当する信号・車上保安装置の実装は確認できなかった。

## ユーザー提供資料から確認した設計条件

- 信号灯の外観要件：4灯式A形・4灯式B形・5灯式A形を使用し、6灯式と5灯式B形は使用しない。消灯レンズは `#111111`・不透明度92%。フェードは消灯180 ms、点灯120 ms、切替暗転40 ms、YG点滅375 ms。
- 通常画面には信号名、閉そくID、ATS照査速度、停車基準、デバッグ文字を表示しない。入換信号と本線信号の役割を区別する。
- スクリーンショット上の現示・制限値は、停止R、警戒YY 25 km/h、注意Y 45 km/h、減速YG 75 km/h、抑速YG点滅105 km/h、進行G 120 km/h。これはユーザー提供の画面資料に記載された値として扱い、実設備の公式値とはみなさない。
- 説明書はYGを70または75 km/h、YG点滅を100または105 km/hとし、差異を未解決としている。したがって70/75および100/105のいずれかを独自に選ばない。
- 説明書は品川進入付近の25 km/h制限を重点条件に挙げるが、対象線路・方向・適用開始/終了位置は示していない。
- 5～20 mのパターン余裕、0.972/1.11 m/s²、450 ms、非常制動に関する4.0 km/h/sは記載されているが、各値の適用条件・単位上の意味が未確定。
- 品川付近のPパターン停止、注意から進行への早すぎる遷移、ATS解除不能、防護無線誤発報、停車目標通過は説明書で報告されているが、現在のコードには対応する信号/ATS状態機械・イベントがなく、現行実装上の再現として確認できない。

## 重大な不足と未確認事項

1. 信号機の位置、対象線路、進行方向、閉そく区間の定義がない。品川進入付近の25 km/h制限についても、該当するエッジ範囲を特定できない。
2. 現示を決める進路・先行列車・閉そく条件がない。
3. C-ATSの照査速度曲線、制動開始条件、常用/非常制動、解除条件がない。説明書にある複数の減速度・余裕距離・制御遅延も適用条件が不明。
4. 図上距離と実距離・速度単位の対応がない。したがって既知の km/h 制限を現在の座標尺度へ変換できない。
5. 進路解放と編成最後尾の関係が信号制御へ接続されていない。

上記は「未実装」または「資料不足で判断不能」に分類する。既存コードに実装済みだが実車仕様との一致を未確認、と扱える信号/C-ATS機能も確認できなかった。

## 次の実装に必要な入力

- 信号・閉そく・速度制限位置データと対象線路/方向（少なくとも品川進入25 km/h区間の開始/終了位置）
- 現示決定および進路設定・解放のルール
- C-ATS速度照査・制動・解除の仕様と列車性能値
- 配線図座標から距離・速度単位への対応、または物理距離を持つ線路データ

表示要件だけを先行実装すると、実在しない位置に信号を描画したり、表示と運転制約が分離したりするため行わない。線路・信号位置データと適用条件がそろった段階で、現示・C-ATS状態・列車運動・イベント記録を一体で実装し、品川の重点ケースを含む回帰検証を行う。

これらを受け取った後、出典または仮定を各データ項目に付け、制約データと列車運動を接続する。データがそろうまでは、C-ATS準拠や実車相当を表示・主張しない。

# フェーズ4 調査記録：信号・速度照査

## 結論

現状の `index.html` には、手動列車の信号現示計算、閉そく信号、C-ATS速度照査の実装が見当たらない。ユーザー提供の信号・C-ATS説明書とスクリーンショットから、表示上の要件と一部の数値は確認できたが、信号位置・対象線路/方向・図上距離と実距離の対応・複数の制動値の意味はまだ確定できない。したがって、これらを実際の運転制約として列車へ適用する変更は行わない。

## 調査した実装

- 線路エッジはノード接続・方向・高架フラグを持ち、長さは図上座標から `Math.hypot` で算出される。閉そく境界、信号位置、速度制限値はエッジデータにない。
- 手動列車は `ACC`、`VMAX` と次の停車目標、先行列車との区間占有を使って走行する。信号現示や照査曲線を運動制御へ渡す経路はない。
- 線路エッジ長は配線図の SVG 座標上のピクセル距離で、現行の手動列車は `VMAX = 30`、`ACC = 28` の図上単位で移動している。駅間実距離との換算がなく、映像から採用した km/h 値をこの運動へ適用できない。
- 「根古屋信号場」の `sigStraight` / `sigSiding` は時刻表列車の経路選択用で、信号現示・車上速度照査ではない。
- 時刻表列車は別の `ttFollow` で予定位置に追従し、追従間隔と回復速度を制限する。C-ATSモデルは確認できない。
- `index.html` 内を `C-ATS`、`ATS`、`speedLimit`、速度照査、信号現示、速度制限の語で検索したが、該当する信号・車上保安装置の実装は確認できなかった。

## ユーザー提供資料から確認した設計条件

- 信号灯の外観要件：4灯式A形・4灯式B形・5灯式A形を使用し、6灯式と5灯式B形は使用しない。消灯レンズは `#111111`・不透明度92%。フェードは消灯180 ms、点灯120 ms、切替暗転40 ms、YG点滅375 ms。
- 通常画面には信号名、閉そくID、ATS照査速度、停車基準、デバッグ文字を表示しない。入換信号と本線信号の役割を区別する。
- スクリーンショット上の現示・制限値は、停止R、警戒YY 25 km/h、注意Y 45 km/h、減速YG 75 km/h、抑速YG点滅105 km/h、進行G 120 km/h。これはユーザー提供の画面資料に記載された値として扱い、実設備の公式値とはみなさない。

## 重大な不足と未確認事項

1. 信号機の位置、対象線路、進行方向、閉そく区間の定義がない。品川進入付近の25 km/h制限についても、該当するエッジ範囲を特定できない。
2. 現示を決める進路・先行列車・閉そく条件がない。
3. C-ATSの照査速度曲線、制動開始条件、常用/非常制動、解除条件がない。説明書にある複数の減速度・余裕距離・制御遅延も適用条件が不明。
4. 図上距離と実距離・速度単位の対応がない。したがって既知の km/h 制限を現在の座標尺度へ変換できない。
5. 進路解放と編成最後尾の関係が信号制御へ接続されていない。
